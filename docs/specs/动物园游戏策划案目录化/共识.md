# 动物园游戏策划案目录化 共识

## 目标

把 `策划/动物园游戏完整策划案.md`（44KB、20 节）按“页面 / 系统 / 规范”拆成一个目录：一个页面一个文件，界面写界面、跨页面规则只写一处，便于逐页审阅和当 UI 验收清单用。

## 已定决策

1. **四层结构**：`README.md` + `页面/` + `系统/` + `规范/` + `数值/`。理由：页面文件只回答“这界面长什么样、点了发生什么”，所有跨页面规则进 `系统/`，页面里只放链接不复制正文，保证规则单一权威出处。
2. **统一页面模板九节**：状态与入口 / 布局 / 界面元素 / 交互 / 规则引用 / 数据依赖 / 边界与异常 / 待你确认的项（另有文件标题与一句话职责）。缺失内容写“无”，不删节。理由：可逐页比对、可直接当验收表。
3. **审阅标记行内化**：正文用 `【建议】` 行内标记，页面末尾只汇总“本页待确认 N 项”。理由：利于集中审阅，不把标记堆成第二份列表。
4. **原文原案删除**，由 git 历史承担归档，`README.md` 注明“由 V0.1 审阅稿拆分而来”。理由：留两份全文必然出现两套口径。前提是原文对照表核完确认无漏。
5. **过程记录保留原样**：`动物园游戏策划讨论记录.md`、`动物园游戏策划讨论交接.md` 不动内容，README 标注“仅供追溯，与正文冲突以本目录为准”。其指向旧文件的链接会失效，属可接受的历史残留。
6. **数值草案不拆散**：移到 `策划/动物园游戏策划案/数值/数值草案.md`，README 引用；页面中凡涉及具体数字只写“→ 数值草案”，不复制值。理由：86 任务表、生成器参数、价格表是跨页面整表，拆开必然重复且难核对。移动时需修掉它内部指向旧主案的链接。
7. **新增 `页面/15-庆祝与提示浮层.md`**：装 100% 完成提示、区域开放／施工牌移除、主线收尾补给反馈三类。
8. **跨页面通用界面规范**集中在 `页面/00-页面与窗口总表.md` 的“通用界面规范”一节（弹窗回原场景、切场景释放交互锁、交易确认必有取消、红点只指可领、隐藏UI与恢复按钮通则），不另立文件。首页只写隐藏UI在首页的摆放与恢复。
9. **不建 `区域/` 目录**（方案 A）。区域信息只作为 `系统/03-任务与解锁.md` 的阶段表与 `系统/07-园景建设与完成.md` 的队列表存在。理由：当前每个区域除“任务区间＋建设件数＋园景 ID 区间”外没有独立内容，拆 8 个近乎空的壳没有收益；将来区域长出专属玩法再拆。
10. **严格搬家（A 档）**：只移动、拆句、补链接；同一规则多处出现时选一处作权威正文，其余改链接。不新增规则、不改数值、不改措辞含义。发现的原文矛盾或缺口只进 README 的“待澄清清单”，不当场裁决。
11. **`页面/01-加载.md` 保留**，只写启动时序与档位（加载什么、失败怎么提示、校时失败怎么办），不把启动流程塞进首页。
12. **编号规则**：`页面/` 用两位数字前缀，按玩家动线排序（00 总表 → 01 加载 → 02 首页 → 03 合成棋盘 → 04 任务 → 05 待领 → 06 体力 → 07 恢复 → 08 气泡 → 09 商店 → 10 背包 → 11 签到 → 12 广告累计 → 13 设置 → 14 小镇 → 15 浮层）；`系统/` 用编号表达阅读依赖（01 生成器与成长 → 02 体力与时间 → 03 任务与解锁 → 04 引导 → 05 广告与钻石 → 06 气泡 → 07 园景建设与完成 → 08 存档与服务器）；`规范/` 不编号（查阅型参照，无先后）。
13. **README 承担四件事**：文档地图、原文逐节对照表（含一主题多落点的多目标映射）、覆盖校验结论（20/20 节已落位）、待澄清清单与项目级待办（含“10 个园景摆放数据缺口”这类资源待办）。
14. **核完即删**：对照表逐节确认无漏后，删除 `策划/动物园游戏完整策划案.md`，不留 `_archive/`、不留跳转壳。

## 不做什么

- 不改任何游戏代码、框架、资源、服务器；只动 `策划/` 下的 markdown。
- 不改任何数值、不裁决原文矛盾、不补编新规则。
- 不拆数值草案的 86 条任务表与参数表。
- 不建 `区域/` 目录，不建 `_archive/`。
- 不改写两份讨论记录／交接的内容（含其中已失效的旧链接）。
- 不为“页面模板某节为空”自行编造规则。

## 验收标准

- 目录树与共识第 1、12 条完全一致，页面文件 16 个（00–15）。
- 原文 20 节在 README 对照表中逐节有落位，标注“覆盖校验 20/20”。
- 每条规则只有一处权威正文，其余位置为链接，无复制性重复。
- 无新增规则、无改动数值、无改动结论；所有原有“建议／试算／沿用”性质在拆分后仍可辨识。
- 每个页面文件九节齐全，空节写“无”。
- `策划/动物园游戏完整策划案.md` 已删除，`数值草案.md` 已移动且内部链接有效。
- 两份过程记录内容与之前逐字一致。
