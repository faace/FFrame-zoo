# 动物园跟框架 共识

## 目标

把 FFrame 模板里改过的控件皮肤加载方式同步进 FFrame-zoo，让动物园在当前 0.10.2 框架下能开机，现有按钮和弹窗有皮。不新增玩法或页面内容。

## 结果

已完成（`0831642` 皮肤与版本；`37dafe3` 标题木牌跟框架图集对齐）。

## 已定决策

1. **只同步已有控件能跑起来所需要的东西。** 动物园已经在用 `PfGMBtn`、`GMFrame`、`applySkin`。这一窗让它们在 0.10.2 的主题图集下继续工作。动物园业务（含设置页音乐 / 音效 / 振动）不在本窗。
2. **皮肤从 FFrame 现成的 `ZooV7` 拷入。** 来源是 `FFrame/assets/game/bundles/Skin/ZooV7/` 的 `ctrl`、`item` 的 png、plist，以及配套 meta，保证 `panel` 子图 uuid 稳定。`config.skinTheme` 写成 `ZooV7`。不从 FFrame-asset-line 重导，不跑 `tools/export-zoo-v7-plist.mjs`。理由：那份导出脚本会把槽名改回旧名；FFrame 里这份已经是游戏用的一半尺寸，并且槽名是 `slider_fill`、`input`。
3. **旧的 28 张散 png 从动物园 `Skin` 包删掉。** `FFrame-asset-line/legacy/Skin-LegacyV3-game/` 里已有同名旧图，不覆盖那份。理由：0.6.0 起包根散图不会被加载，留着只会变成丢失引用。
4. **10 个弹窗预制体只改 `panel` 的 Sprite 帧。** 删旧图时改到拷过来的 `ZooV7` 的 `panel` 子图。不改节点结构，不往 `body` 里填业务内容，不动 `PfZooHomeYard`。
5. **版本声明写成正在跑的框架版本。** `assets/game/config.ts` 的 `version.gmajor` 与 `extensions/gmajor/package.json` 的 `version` 都是 `0.10.2`，挂载路径 `../../../FFrame/gmajor` 不动。
6. **业务脚本不动。** `HomeHud`、棋盘、任务，以及 `ScZooHome` 里现有的按钮和 `applySkin` 调用都不改。走皮肤槽的控件会跟着新图集变，那是换皮生效。

## 不做什么

- 不给动物园设置页加音乐滑条、音效滑条、振动开关（那是动物园业务，另开）。
- 不搬 FFrame demo 的 `LyControls` / `DemoHome/LySetting` 演示内容进动物园。
- 不往 9 个空壳弹窗（除设置骨架以外的业务窗）里填内容。
- 不改 `HomeHud`、棋盘、任务、`ScZooHome`、`PfZooHomeYard` 的脚本和场景。
- 不改 FFrame 的 `gmajor/`，不改控件脚本来迁就动物园。
- 不覆盖 `FFrame-asset-line/legacy/Skin-LegacyV3-game/`。
- 不做列表回收、双窗 / `wireCall`。`count_plate` 已在图集侧去掉，动物园也不做。

## 确认框

另窗已接上（`7de5b04`）。`ZooHome/LyAlert` 嵌 `PfGMTitle` / `PfGMBtn`，吃通用皮 `ZooV7`；`ZooHomeEntry.onBind` 预载并 `setAlertPrefab`。首页临时入口 `确认框` 调 `gu.alert` 验收。**没特殊情况就用通用的**，不为确认框另做图。

## 验收标准

- `config.version.gmajor` 与 `extensions/gmajor/package.json` 的 `version` 都是 `0.10.2`，挂载路径仍指向 `../../../FFrame/gmajor`。
- `assets/game/bundles/Skin/ZooV7/` 有 `ctrl`、`item` 的 png 和 plist；`config.skinTheme` 为 `ZooV7`；`Skin` 包根不再有那 28 张散 png。
- 上述 10 个 `Ly*` 预制体的 `panel` Sprite 指向 `ZooV7` 的 `panel` 子图，节点结构与改前一致。
- 开机没有「没有可用的界面图」。设置弹窗能开，标题是「设置」，有关闭，底框和标题条不是白图。
- `HomeHud`、棋盘、任务的脚本和预制体与改前一致（皮肤槽换成新图集不算改这些文件）。

## 涉及范围

- `FFrame-zoo/assets/game/config.ts`
- `FFrame-zoo/extensions/gmajor/package.json`（只改 `version`）
- `FFrame-zoo/assets/game/bundles/Skin/`（删包根散图，放入 `ZooV7/`）
- `FFrame-zoo/assets/game/bundles/ZooHome/` 下那 10 个 `Ly*.prefab`（只改 `panel` 的 Sprite 帧）
- 只读来源：`FFrame/assets/game/bundles/Skin/ZooV7/`
- 不改：`FFrame/gmajor/`、`FFrame-asset-line/legacy/Skin-LegacyV3-game/`、动物园业务脚本
