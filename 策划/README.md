## 已经定下，讨论时不要重开

- 开场只有一张背景，各区是没开工的草地。八个区各放一份施工牌，段一开始就拿掉，换成这一区的园景。施工牌和空地面都不进队列、不计百分比。预定元素再摆到既定位置，百分比到 100%。到了可以走进参观，不能再加。小镇这一格换成完成图。完成是一次达成。
- 大约一周是内部粗算，应用里不告诉玩家。不能靠连续玩 24 小时通关。主循环打满大约一周仍不够，签到和广告补缺。没来的日子签到不加。当天拿到的元素当天可以布置。
- 设计分辨率 720×1280。手机定宽，iPad 定高。核心画面不拉伸、不裁切。
- 不改 64 格地图。不上架，不写小镇格子的下载和跳转。
- 这一家的主循环是持久棋盘上的两两合成。细节在已定.md。
- 账号服务器见下一节。时间、拉存档、写回都走那一台。

## 账号服务器

2026-10-04 记下。服务器工程在 `d:\node\wenodejs`，域名 `https://www.farain.com`。`app` 目录里一个文件夹挂一条路由，HTTPS 已经在听。动物园要用的时间、拉存档、写回，以后加进这个工程。这次不在这里写路径，也不在 FFrame 里接。

- 协议用 HTTPS。这次不用 WebSocket。以后可以两种一起用，这次不写 WebSocket。
- 加载页要的服务器时间、账号存档的拉取，以及玩的时候写回，都走这个服务器。
- 写回的时机仍是：结果一变就写。若并发扛不住，棋盘这类再改成定时上报。要时间仍马上问。
- 框架里的 `GMRemoteAdapter` 仍是本机假服，只有拉取，没有写回，也没有时间接口。接这台服务器之前，不在假服上把这套做完。
