## 统一约定

所有弹窗继承 `ZooLayer`（不是直接 `GMLayer`），顶栏由基类统一建，子类只填内容。

- **内容一律挂 `this.body`**。这是基类建好的节点，已按标题条下沿到面板底边算好尺寸，不要再往 `panel` 上直接加。
- **改标题用 `this.setTitle('字样')`**，不要自己摆标题条。
- **关闭钮由基类建好**，`LyXxx` 的 `node.name` 必须是预制体文件名（`gu.closeLayer(this.node.name)` 靠它）。
- **面板尺寸**是 620×800，由预制体里 `panel` 的 `UITransform` 决定；`ZooLayer.ts` 里的 `PANEL_W`／`PANEL_H` 是同一份值，改尺寸两处一起改。
- **不要改预制体的节点树**去加顶栏，运行时会重复。

## 新建弹窗

用 `tools/create-ly-prefab.mjs`（从 FFrame 复制并改成走 `db://gmajor`）：

```
node tools/create-ly-prefab.mjs assets/game/bundles/ZooHome LyXxx
```

生成后手工两步：

1. 把 `LyXxx.ts` 的基类从 `GMLayer` 改成 `ZooLayer`，`onInit` 改成 `protected onLayerInit(): void { this.setTitle('…'); }`。
2. 把预制体里 `panel` 的 `UITransform` 尺寸改成 620×800，并给 `panel` 加一个 `cc.Sprite`（`Skin/panel.png`，`SLICED`）。

## 字体

统一走 `ZooFont.ts` 的 `preloadZooFont()` + `zooFont()`，不要在别处重复加载。字体是 `db://gmajor/fonts/main.ttf`（uuid `ee40121d-0b21-4bb3-b95c-fa7d2df322b4`）；载不到时退回系统字体，不阻塞。

## 内容排版

- 面板 620×800，标题条 85 高，占掉顶部约 57；`body` 可用区约 572×695。
- 按钮用框架 `PfGMBtn`：中档 260×88、大档 380×120，没有更小的档位。
- 文字用 `cc.Label` 挂 `main.ttf`，标题色 `(92,64,32)` 深墨，正文白字配 3 像素深褐描边。
- 图标取 `Skin` 包：`icon_close`、`icon_diamond`、`icon_gold`、`icon_energy`、`icon_ad`、`icon_settings`、`icon_help`、`icon_music`、`icon_sfx`、`icon_plus`、`icon_minus`、`slot_item`。

## 边界与异常

- 弹窗打开期间切场景会全部关掉，不走 `onLeave`。
- 缺 `panel` 的 `Ly*` 预制体会直接抛错（`GMLayer.ensureLayerChrome`）。
- loading 开着时按钮不响应（`gu.addClick` 内部拦）。
