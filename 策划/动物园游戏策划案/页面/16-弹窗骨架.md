## 统一约定

所有弹窗继承 `ZooLayer`（`ZooLayer` 继承框架 `GMFrame`）。顶栏和底框由骨架建，子类只填内容。

- **内容一律挂 `this.body`**。有标题时，这块在标题条下沿和面板底边之间。没标题时，从木框内沿开始，不给标题留空。
- **改标题用 `this.setTitle('字样')`**。不要标题时把字段 `showTitle` 写成 `false`，不是靠不调用 `setTitle`。
- **关闭钮默认就在**，点了关自己。不要时把 `showClose` 写成 `false`。
- **底框默认就在**。不要时把 `showPlate` 写成 `false`。关掉的是木框，遮罩还在，标题和按钮的位置不变。
- **左上角**要出现就 `this.setLeft(回调)`，图标默认 `icon_help`。要换图标再传第二个参数。没回调不出现。
- **尺寸**默认 620×800。不同才在子类上写 `width` / `height`。
- **关闭钮和左上角与标题垂直居中**，铆钉压在面板棕色顶边上。没有标题时，这两颗钮仍停在这条边上。
- **`LyXxx` 的 `node.name` 必须是预制体文件名**（`gu.closeLayer(this.node.name)` 靠它）。
- **不要在预制体里再搭一套标题或关闭钮**，运行时会重复。

细则在 `FFrame/docs/specs/弹窗骨架/共识.md`。

## 新建弹窗

用 `tools/create-ly-prefab.mjs`（从 FFrame 复制并改成走 `db://gmajor`）：

```
node tools/create-ly-prefab.mjs assets/game/bundles/ZooHome LyXxx
```

生成后把 `LyXxx.ts` 的基类从 `GMLayer` 改成 `ZooLayer`，`onInit` 改成 `protected onLayerInit(): void { this.setTitle('…'); }`。尺寸、底框不用再在预制体里改。

## 字体

统一走 `ZooFont.ts` 的 `preloadZooFont()` + `zooFont()`，不要在别处重复加载。字体是 `db://gmajor/fonts/main.ttf`（uuid `ee40121d-0b21-4bb3-b95c-fa7d2df322b4`）；载不到时退回系统字体，不阻塞。标题条本身用框架 `PfGMTitle`，字已经挂在这套字体上。

## 内容排版

- 默认面板 620×800。标题条 85 高，铆钉压在顶边棕色框上。
- 按钮用框架 `PfGMBtn`。关闭和左上角是中档纯图标。
- 文字用 `cc.Label` 挂 `main.ttf`，标题色 `(92,64,32)` 深墨，正文白字配 3 像素深褐描边。
- 图标取 `Skin` 包：`icon_close`、`icon_diamond`、`icon_gold`、`icon_energy`、`icon_ad`、`icon_settings`、`icon_help`、`icon_music`、`icon_sfx`、`icon_plus`、`icon_minus`、`slot_item`。

## 边界与异常

- 弹窗打开期间切场景会全部关掉，不走 `onLeave`。
- 缺 `panel` 的 `Ly*` 预制体会直接抛错（`GMLayer.ensureLayerChrome`）。
- loading 开着时按钮不响应（`gu.addClick` 内部拦）。
