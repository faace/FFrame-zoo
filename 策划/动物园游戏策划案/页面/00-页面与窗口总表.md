# 页面与窗口总表

一句话职责：列出全部界面、它们之间的关系，以及所有界面共用的通则。

## 通用界面规范

以下规则适用于所有页面与窗口，各页面文件不再重复。

- 弹窗关闭回原场景；切场景关闭普通弹窗并释放交互锁，广告播放和不可分割交易期间禁切。
- 【建议】弹窗外点击可关闭信息类窗口，交易确认用明确取消／关闭按钮，不用点背景确认购买。
- 所有购买按钮在确认前展示币种、价格、数量、余额和所得去向。
- 红点只指当前可领取内容，不用"未付费""未升级"常驻红点施压。
- 隐藏物品永不出现在奖励列表、背包、商店、棋盘等任何玩家界面；可以展示解锁效果和本体图。
- 所有可操作UI避安全区和右上小程序胶囊。
- 切后台停止声音，返回不叠播。
- 每次有效状态变动先在本地形成完整结果和操作ID、保存成功后反馈，再按序同步；详见 [系统/08-存档与服务器.md](../系统/08-存档与服务器.md)。
- 反馈动画【建议】普通 150～350 毫秒、建设约 400 毫秒、区域庆祝不超过 2 秒；跳过只缩短表现、不跳过结算。

## 窗口行为表

| 窗口 | 主内容 | 成功后 |
|---|---|---|
| 任务详情 | 需求、来源、合成链、奖励、提交 | 关闭详情，留合成 |
| 体力 | 当前／上限、自然恢复、广告和钻石恢复 | 留窗，刷新余额，不自动生产 |
| 冷却 | 对应本体、次数／容量、当前轮倒计时、减时和立即完成 | 当前轮完成自动关窗，不自动生产 |
| 气泡 | 内含物、剩余时间、钻石／广告、放弃 | 解锁留原格；放弃移除 |
| 商店 | 标签、商品、限购、刷新倒计时 | 留窗，棋盘物品进待领 |
| 背包 | 格子、物品、扩容、取出 | 留窗；取出需棋盘空格 |
| 待领奖励 | 分类图标、名称等级、数量、选择领取 | 单次取1件，空列表关闭入口 |
| 签到 | 7次累计奖励、今日状态、领取 | 留窗，刷新红点 |
| 广告累计奖励 | 进度／目标、奖励、领取、来源说明 | 领后进度归零，留窗 |
| 设置 | 音乐、音效、振动 | 立即本地保存 |

## 场景与窗口关系

- 两个全屏场景：首页与合成棋盘，互相切换。
- 小镇从首页进入，返回首页。
- 加载在最前，进入首页后不再返回。
- 其余为弹窗或常驻条，覆盖在当前场景上。
