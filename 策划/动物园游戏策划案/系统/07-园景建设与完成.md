### 摆位数据与预制体（工作约定）

园景的位置、缩放、锚点以 `assets/game/bundles/ZooHome/scenery.json` 为准；`PfZooHomeYard.prefab` 是同一份数据的可视化版本，供在 Creator 里拖摆。

- 改法：双击打开 `PfZooHomeYard.prefab`，调 position／scale，保存。节点名就是资源 ID（`SouthGate/gate_01` 对应节点名 `SouthGate_gate_01`），**不要改名**。
- 回写：在工程根执行 `node tools/sync-yard-from-prefab.mjs`，把预制体的 position／scale 写回 `scenery.json`；先加 `--dry` 可只看差异。
- 反向不自动：直接改 `scenery.json` 不会更新预制体，需要重新生成。
- 运行时不读预制体：`ScZooHome.ts` 在运行时按 `scenery.json` 动态建节点并打 `DontSave`，所以预制体只是编辑器里的可视化工具。**不要把 `PfZooHomeYard` 挂进 `ScZooHome.scene`**，否则会和运行时动态创建的节点重复渲染。
- `anchor` 不要手调：它等于 PNG 底部透明留白 ÷ 图片高度，每张贴纸各不相同；改锚点会让垂直位置错位。位置调整用 position，大小用 scale。

数据字段含义：

| 字段 | 含义 |
|---|---|
| `place` | 统一为 `foot`，表示该件按脚点定位 |
| `foot` | 锚点落在母图（1440×2560，左上原点）的像素坐标，`foot = [cocos.x×2, 2560 − cocos.y×2]` |
| `cocos` | 运行时的节点位置与缩放，画布 720×1280、左下原点 |
| `anchor` | 锚点在 PNG 内的比例，由切图留白算出 |
| `order` | 同层绘制先后，决定遮挡；与建设顺序无关 |
| `queueIndex` | 建设顺序 1—86；与 `order` 独立 |
| `masterBox` | 场地覆盖的母图矩形，仅供核对，运行时不读 |
| `inQueue` | 是否计入 86 件建设队列 |

## 建设操作

有素材点击建设放下一项；无素材置灰但允许点击解释"完成合成任务获得园景素材"。一次扣 1，建设结果和素材扣除一次保存，动画只负责表现。播放期间禁重入。

配置有短对话的项目先弹文字，确认后重新检查素材和队列、扣料建设；取消或退出不扣。【建议】可取消对话；对话不自动跳过。长按 450 毫秒开始连续建设，每项动画结束后检查是否继续；松手、耗尽、100% 或遇对话停止。确认对话只建当前项，不恢复长按。

建设百分比按已建件数／86 计算，UI 显示整数向下取整，最后一件之前不得四舍五入到 100%。区域开始时自动移除该区施工牌、覆盖对应地面，不消耗素材、不计件数；普通可建设指示牌仍计数。

按钮与百分比在首页的呈现见 [页面/02-首页.md](../页面/02-首页.md)；区域开放与完成提示的表现见 [页面/15-庆祝与提示浮层.md](../页面/15-庆祝与提示浮层.md)。

## 区域开放

南门初始开放；其余阶段在上一段建设累计达到阈值后开放（阈值表见 [03-任务与解锁.md](03-任务与解锁.md)）。区域开放时把本段任务追加到待补序列，旧卡保留。

## 100% 收尾【沿用方向，补齐建议】

最后一件建设保存成功后，原子执行一次主线收尾：关闭并归档未完成主线卡／待补任务；保留棋盘、背包、待领、货币、生成器和成长进度；今后签到、广告累计奖励忽略园景素材项目，其他照发。素材余额保留但不能继续建设。

为避免额外素材提前 100% 导致必要内容丢失，【建议】收尾补发所有未完成主线中的"唯一解锁效果及成长零件"，仍经过正常去重与满级替代规则；不补发这些任务的金币、钻石、园景素材，不扣任务需求。已发放的零件不重复发。补发反馈为"主线收尾补给"，实物进入待领；未做完的首次引导以后仍可继续，不强迫此刻升级。

最终完成提示只显示一次，按钮"欣赏园区"和"继续游玩"；欣赏使用首页隐藏 UI 模式。退出发生在保存后、弹窗前时，下次补显示一次。100% 以后不生成新的主线或循环任务，首版保留生产、合成收集、出售、成长、签到、广告和商店，日常奖励仍可领，但不承诺无限经营内容。

## 边界与异常

- 建设对话后素材变化：确认时重验，不足则不扣不建。
- 额外素材提前 100%：先归档主线并补未发唯一解锁／成长，再撤卡，防必要奖励消失。
- 已建 ID 保留，物品与园景 ID 不复用。
- 配置引用缺失：发布前阻止该版本。
