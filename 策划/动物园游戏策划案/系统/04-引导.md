# 引导

一句话职责：每条引导用独立进度物品记录已完成步骤，可中断、排队、续做。

## 进度模型【沿用】

每条引导使用自己的隐藏进度物品，数量 0 表示未完成任何步骤，N 表示至少完成至第 N 步。完成步骤取最大值，不盲目加 1；没有全局同义计数。任务解锁、物品发现记录和引导进度各自承担不同含义。

## 各条引导

| 引导 | 触发 | 步骤与完成判定 |
|---|---|---|
| 开局 | 新档、尚未完成 | 进棋盘→生产两份小树枝→合成粗树枝→交001→回首页→放第一件；每步以实际状态／成功事件确认 |
| 工具箱 | 已解锁且未完成 | 打开待领→选择工具箱领取→点击生产小锤子 |
| 首次零件合成 | 棋盘已有两份同级对应零件 | 高亮可合成对→合成成功；不要求某个固定格位 |
| 首次套件使用 | 已有套件及可升级对应本体 | 拖向本体→查看确认→成功升级；取消时保留步骤、允许稍后做 |
| 动物／植物／餐食 | 对应本体已解锁 | 简短介绍领取和产出；首次实际产出完成，不重复完整开局教学 |
| 清洁／导览 | 服务柜解锁后各路线首次实际产出 | 各自一次提示并记进度；不强求第一下出某路线 |
| 小镇 | 首次开放 | 首页按钮弱提示，进入后介绍拖缩与定位，不强制中断主循环 |

## 固定产物覆盖

开局木料前两次产出固定小树枝；工具箱第一次固定小锤子，仍消耗正常体力与次数。后续生成器首个产物【建议】固定本路线 1 级；服务柜按正常双路线规则产出，不为教学增加一次隐藏解锁。

## 反馈顺序与恢复

任务结算保存→奖励／解锁反馈→反馈关闭→按配置优先级排引导。已有引导进行时新引导入队，不相互覆盖。暂停、满盘、无体力、冷却、退出不重发奖励；重新打开对应界面时继续。对可持续状态（已领取、已解锁）直接检查，对一次性动作在成功时推进对应步骤，不能通过重新打开界面假定动作已做过。

## 引导的可中断要求

【建议】引导期间允许关闭或暂停提示去整理棋盘；开局关键动作以高亮和文字引导，不用不可退出遮罩形成死锁。签到不作为强制引导步骤，不自动弹出。

## 边界与异常

- 满盘领本体／零件：引导可暂停，不要求购买背包。
- 暂停、满盘、无体力、冷却、退出不重发奖励。
- 引导变更须按稳定步骤含义映射，不能直接把旧计数套进全新步骤。
