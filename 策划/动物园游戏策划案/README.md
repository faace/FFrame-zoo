## 1. 产品目标与首版范围

玩家通过持久棋盘上的生产、二合一与交任务，逐步建成一座动物园。一次建设带来一个可见变化，长期目标是完成整座园子并欣赏成果。

核心循环：消耗体力生产 → 合成任务物品 → 提交任务 → 获得通用园景素材 → 按队列建设 → 开放后续任务与内容。

【沿用】没有玩家等级、经验、升级回满体力或真实货币支付；物品与生成器可以有自身等级。没有每日必须完成额度，也没有必须次日签到或观看广告才能推进的门槛。"约7天"只用于内部测算，不对玩家承诺、不设置日历锁。

首版包括：首页、合成棋盘、小镇、加载、设置、签到、广告累计奖励、体力、生成器冷却、气泡、商店、背包、待领奖励、任务与引导、账号存档。首版不做游客经营收益、动物喂养、装饰自由摆放、重复建设、付费充值、排行榜、社交、其他小镇应用的下载或跳转。

## 2. 内容与术语

| 名称 | 定义 |
|---|---|
| 棋盘物品 | 占一格的普通物品、生成器、零件、套件或气泡 |
| 园景素材 | 数值资源；1份用于放置固定队列里的下一件园景，不指定某种建筑 |
| 园景 | 首页实际放置的建筑、动物、植物、人物、设施 |
| 生成器 | 消耗体力和储存次数，在棋盘产出物品的本体 |
| 零件／升级套件 | 同类零件二合一得到套件，套件用于升级已有生成器 |
| 隐藏解锁物品 | 任务奖励的内部物品，执行功能解锁，不在玩家界面展示 |
| 隐藏引导进度物品 | 每条引导独立持有，数量表示完成到第几步 |

七条普通路线与六种生成器的具体清单见 [系统/01-生成器与成长.md](系统/01-生成器与成长.md)。

## 3. 从新档到完成的流程

1. 加载本地设置、配置与必要资源，取得服务器时间，拉取／创建账号存档，进入首页。
2. 新档显示开场背景、各区施工牌、南门可建设状态；引导进入合成。
3. 棋盘只有可用木料站，生产两份小树枝并合成粗树枝，提交首任务。
4. 获得素材后引导回首页建设第一项。建设不随交任务自动发生。
5. 南门任务奖励工具箱解锁物品；教领取本体并首次生产。
6. 后续按阶段解锁其余生成器，任务穿插新旧路线。玩家自行在合成与首页之间往返。
7. 放完86件园景到达100%；主线建设任务退出，棋盘和其他非主线功能保留。

【建议】引导期间允许关闭或暂停提示去整理棋盘；开局关键动作以高亮和文字引导，不用不可退出遮罩形成死锁。签到不作为强制引导步骤，不自动弹出。

启动时序细节见 [页面/01-加载.md](页面/01-加载.md)；解锁顺序见 [系统/03-任务与解锁.md](系统/03-任务与解锁.md)；引导步骤见 [系统/04-引导.md](系统/04-引导.md)；建设与收尾见 [系统/07-园景建设与完成.md](系统/07-园景建设与完成.md)。
