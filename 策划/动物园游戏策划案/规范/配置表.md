# 配置表

一句话职责：约定各配置表的字段含义与校验要求，不要求本轮实现表工具或脚本平台。

优先普通表格＋关联校验，代码提供有限通用效果；不为任意任务写任意脚本。

## 表与字段

| 表 | 主要字段 | 缺省及约束 |
|---|---|---|
| 物品 | id、分类、链、等级、名称、图标、mergeTo、售价、可收纳、可出售 | ID 永久稳定；普通链除末级必须有合成目标；本体／零件／套件禁止出售；隐藏分类禁止玩家展示 |
| 生成器等级 | generatorId、level、每轮次数、时长、容量、产出组、升级目标 | 次数和容量正整数，容量≥一轮；不减容量；首轮升级不降低效率 |
| 产出组 | groupId、路线权重、等级权重、首次产出覆盖 | 权重非负且总和>0；初始本体始终保留 1 级来源；双路线必须都有来源 |
| 零件链 | generatorId、partItemIds、kitItemId、可升目标 | 不同本体零件不混；套件目标唯一；基础成本可算清 |
| 任务 | id、序号、区域、前置、需求数组、奖励数组 | 1～2 种需求；重复同物品合并计数；禁止自依赖或解锁循环 |
| 奖励 | rewardId、itemId、quantity、满级替代 | 数量正整数；数值直入；棋盘入待领；隐藏执行内部效果 |
| 解锁效果 | hiddenItemId、effectType、target、onceKey | 有限效果：开放功能、发唯一生成器、开放引导；一次性键稳定 |
| 引导 | id、进度物品ID、触发、优先级、步骤、完成条件、提示 | 每引导独立进度物品；不混用经验或全局计数；步骤要有退出与恢复策略 |
| 区域 | id、顺序、开放建设数、地面、施工牌、任务组 | 开放阈值单调；区域任务不能反向依赖未开的下一段 |
| 园景队列 | sceneryId、queueIndex、zone、对话ID、layer、z | 仅 86 个 inQueue 项参与；序号唯一连续；显示层级独立 |
| 新档 | layout、体力／币余额、背包格、初始任务条件 | 棋盘 63 格；仅木料站；不得重进重复建档 |
| 经济与时间 | 体力上限、恢复、每日时区、价格、扩容、阈值 | 默认来自数值草案；时间用秒、概率用明确整数权重 |
| 商店／签到／广告 | id、条件、奖励、次数、价格、刷新／循环规则 | 隐藏物品不可作可见商品；签到 7 次；广告即时成功才统计 |
| 气泡 | 允许物品、概率、寿命、上限、钻石价、广告条件 | 无空格不出；无零件／套件／本体；过期无奖励 |

## 缺省与报错

每条数组字段必须明确空数组含义；可选前置缺省为空，缺省奖励为空；需求、生成器生产和关键资源参数缺失时报错，不静默补 0。价格允许 0 仅限明确免费商品。奖励替代不递归多次，防循环替换。

## 导出前校验

ID 引用、链闭环、解锁依赖图、奖励总量、成长需求总量、各阶段素材累计、牌数与补卡条件、价格合法、空图标、地面／脚点缺口。任何必要引用缺失阻止该版本发布。
