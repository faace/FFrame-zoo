# 异常与并发

一句话职责：逐场景列出必须行为，作为验收与开发的对照表。

| 场景 | 必须行为 |
|---|---|
| 满盘点击生产 | 不扣体力、不扣次数、不抽掉可见产物；允许整理 |
| 满盘领本体／零件 | 奖励留待领，引导可暂停，不要求购买背包 |
| 满背包收纳／满盘取出 | 两端都不变更，不转待领 |
| 两卡共用同一物品 | 先交成功者消耗，其他卡立即重算，不负库存 |
| 交任务后断网／退出 | 扣料与发奖同结果恢复，不能只扣不发或再次补发 |
| 套件错误目标／取消／满级 | 不消耗、不升级；提示后可继续整理 |
| 升级时恢复轮到点 | 先结算到当前时刻，再升级；只补该轮一次 |
| 收纳／取出跨后台 | 收纳时冻结剩余，取出才继续，不计背包离线时长 |
| 广告取消／失败／重复回调 | 失败不奖励不统计；重复成功只发一次 |
| 冷却广告跨轮 | 只影响绑定原轮；原轮已结束不补下一轮、不计额度统计 |
| 气泡广告取消 | 恢复该泡原剩余时间，其他计时从未暂停 |
| 跨日签到／限购／广告 | 每日标记由服务器日判定，进行中广告按发起日预约 |
| 多指／拖出／切后台 | 拖拽取消回合法状态，未确认交易不扣；释放临时操作锁 |
| 建设对话后素材变化 | 确认时重验，不足则不扣不建 |
| 额外素材提前 100% | 先归档主线并补未发唯一解锁／成长，再撤卡，防必要奖励消失 |
| 满级后仍有零件 | 不静默删、不开放普通出售，按专用整理建议预览确认处理 |
| 配置引用缺失 | 发布前阻止；运行时保留存档并提示恢复，不吞用户物品 |
